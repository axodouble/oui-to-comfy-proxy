# oui-to-comfy-proxy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a FastAPI service that exposes OpenAI-compatible `/v1/images/generations` and `/v1/images/edits` endpoints, driving Qwen Image 2.1 in ComfyUI via two JSON workflow templates with automatic 1–16 reference-image mapping.

**Architecture:** Template-based graph surgery: the proxy loads `workflows/imagegen.json` and `workflows/imageedit.json` at startup and mutates deep copies per request (prompt, seed, size, N `LoadImage` nodes wired to `images.image_1..N`). A small async ComfyUI client uploads images, queues prompts, polls history, and fetches results.

**Tech Stack:** Python 3.12, uv, FastAPI, httpx, python-multipart, pytest + pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-09-21-oui-to-comfy-proxy-design.md`

## Global Constraints

- Python 3.12 (pinned in `.python-version`); all commands run via `uv run ...` from the repo root.
- Runtime dependencies only: `fastapi`, `uvicorn[standard]`, `httpx`, `python-multipart`, `pydantic`. Dev: `pytest`, `pytest-asyncio`. No others.
- Workflow nodes are located by `class_type`, never by node ID.
- Edits: 1..16 images (node autogrow limit); `size` and `background` are accepted and ignored; first image sets output size.
- Generation: `size` rounded to nearest multiple of 32, clamped [32, 4096]; `auto`/absent → 1024x1024.
- `n`: default 1, cap 8; every run gets a fresh random 32-bit unsigned seed.
- Error mapping: `RequestError` → 400, `ComfyUIError` → 502, `ComfyUITimeout` → 504, bad/missing Bearer key → 401.
- TDD: write the failing test, watch it fail, implement minimally, watch it pass, commit. One commit per task.

```python
import json
import re
from dataclasses import dataclass
from pathlib import Path

MAX_IMAGES = 16
IMAGE_SLOT_RE = re.compile(r"^images\.image_(\d+)$")


class TemplateError(Exception):
    pass


@dataclass(frozen=True)
class Templates:
    generation: dict
    edit: dict


def _find_node(graph: dict, class_type: str) -> str:
    for node_id, node in graph.items():
        if node.get("class_type") == class_type:
            return node_id
    raise TemplateError(f"no {class_type} node in template")


def load_templates(workflow_dir: str | Path) -> Templates:
    d = Path(workflow_dir)
    generation = json.loads((d / "imagegen.json").read_text())
    edit = json.loads((d / "imageedit.json").read_text())
    for node_type in ("TextEncodeQwenImage21", "KSampler", "SaveImageAdvanced"):
        _find_node(generation, node_type)
        _find_node(edit, node_type)
    _find_node(generation, "EmptyLatentImage")
    return Templates(generation, edit)


def find_save_node_id(graph: dict) -> str:
    return _find_node(graph, "SaveImageAdvanced")
```

```python
def _is_referenced(node_id: str, graph: dict) -> bool:
    """True if any node links to node_id via a [node_id, slot] input value."""
    for node in graph.values():
        for value in node.get("inputs", {}).values():
            if isinstance(value, list) and value and value[0] == node_id:
                return True
    return False


def build_edit_graph(
    template: dict, prompt: str, negative_prompt: str, image_filenames: list[str], seed: int
) -> dict:
    if not 1 <= len(image_filenames) <= MAX_IMAGES:
        raise ValueError(f"expected 1..{MAX_IMAGES} images, got {len(image_filenames)}")
    graph = copy.deepcopy(template)
    text_id = _find_node(graph, "TextEncodeQwenImage21")
    inputs = graph[text_id]["inputs"]
    inputs["prompt"] = prompt
    inputs["negative_prompt"] = negative_prompt

    drop = set()
    for key in list(inputs):
        if not IMAGE_SLOT_RE.match(key):
            continue
        value = inputs[key]
        if isinstance(value, list) and value:
            drop.add(value[0])
        del inputs[key]

    for node_id in drop:
        node = graph.get(node_id)
        if node is None or node.get("class_type") != "LoadImage":
            continue
        if _is_referenced(node_id, graph):
            continue
        del graph[node_id]

    for i, filename in enumerate(image_filenames, start=1):
        node_id = f"oui-to-comfy-proxy_load_{i}"
        graph[node_id] = {
            "inputs": {"image": filename},
            "class_type": "LoadImage",
            "_meta": {"title": f"Proxy Input {i}"},
        }
        inputs[f"images.image_{i}"] = [node_id, 0]

    graph[_find_node(graph, "KSampler")]["inputs"]["seed"] = seed
    return graph
```

Note: the slot keys are deleted before `_is_referenced` runs, so the text node's own (removed) links never count. Slot keys are flat (`images.image_N`), matching the shipped templates; a template re-saved with nested autogrow input dicts would need the removal loop extended, which is out of scope.

```python
import re
import time

MAX_N = 8
MIN_DIM = 32
MAX_DIM = 4096
SIZE_RE = re.compile(r"^(\d+)x(\d+)$")


class RequestError(Exception):
    def __init__(self, detail: str):
        super().__init__(detail)
        self.detail = detail


def _round_dim(value: int) -> int:
    return max(MIN_DIM, min(MAX_DIM, int(round(value / 32)) * 32))


def parse_size(size: str | None, default: tuple[int, int] = (1024, 1024)) -> tuple[int, int]:
    if not size:
        return default
    size = size.strip()
    if size.lower() == "auto":
        return default
    m = SIZE_RE.match(size)
    if not m:
        raise RequestError(f"invalid size {size!r}, expected 'WxH' or 'auto'")
    w, h = int(m.group(1)), int(m.group(2))
    if w <= 0 or h <= 0:
        raise RequestError("size dimensions must be positive")
    return _round_dim(w), _round_dim(h)


def validate_n(n: int | None) -> int:
    if n is None:
        return 1
    if n < 1:
        raise RequestError("n must be >= 1")
    if n > MAX_N:
        raise RequestError(f"n must be <= {MAX_N}")
    return n


def image_response(b64_list: list[str]) -> dict:
    return {"created": int(time.time()), "data": [{"b64_json": b} for b in b64_list]}
```

```python
import asyncio
import uuid

import httpx


class ComfyUIError(Exception):
    pass


class ComfyUITimeout(Exception):
    pass


class ComfyUIClient:
    def __init__(self, base_url: str, request_timeout: float = 30.0, transport=None):
        self._client = httpx.AsyncClient(base_url=base_url, timeout=request_timeout, transport=transport)
        self._client_id = uuid.uuid4().hex

    async def aclose(self):
        await self._client.aclose()

    async def upload_image(self, data: bytes, filename: str, content_type: str) -> str:
        r = await self._client.post(
            "/upload/image",
            files={"image": (filename, data, content_type)},
            data={"overwrite": "true", "subfolder": ""},
        )
        if r.status_code != 200:
            raise ComfyUIError(f"upload failed: {r.status_code} {r.text[:200]}")
        name = r.json().get("name")
        if not name:
            raise ComfyUIError(f"upload response missing name: {r.text[:200]}")
        return name

    async def queue(self, graph: dict) -> str:
        r = await self._client.post("/prompt", json={"prompt": graph, "client_id": self._client_id})
        if r.status_code != 200:
            raise ComfyUIError(f"queue failed: {r.status_code} {r.text[:200]}")
        prompt_id = r.json().get("prompt_id")
        if not prompt_id:
            raise ComfyUIError(f"queue response missing prompt_id: {r.text[:200]}")
        return prompt_id

    async def wait(self, prompt_id: str, timeout: float, poll_interval: float = 0.5) -> dict:
        loop = asyncio.get_running_loop()
        deadline = loop.time() + timeout
        while True:
            r = await self._client.get(f"/history/{prompt_id}")
            if r.status_code != 200:
                raise ComfyUIError(f"history failed: {r.status_code} {r.text[:200]}")
            entry = r.json().get(prompt_id)
            if entry:
                status = (entry.get("status") or {}).get("status_str")
                if status == "success":
                    return entry
                if status == "error":
                    raise ComfyUIError(f"execution failed: {str((entry.get('status') or {}).get('messages'))[:500]}")
            if loop.time() >= deadline:
                raise ComfyUITimeout(f"timed out after {timeout}s waiting for {prompt_id}")
            if deadline - loop.time() <= poll_interval:
                await asyncio.sleep(max(0, deadline - loop.time()))
            else:
                await asyncio.sleep(poll_interval)

    async def fetch_image(self, filename: str, subfolder: str, image_type: str = "output") -> bytes:
        r = await self._client.get(
            "/view", params={"filename": filename, "subfolder": subfolder, "type": image_type}
        )
        if r.status_code != 200:
            raise ComfyUIError(f"view failed: {r.status_code} {r.text[:200]}")
        return r.content
```

```python
import base64
import hmac
import random
from contextlib import asynccontextmanager
from dataclasses import dataclass
from pathlib import Path

from fastapi import Depends, FastAPI, Header, HTTPException, Request
from fastapi.responses import JSONResponse

from .comfyui import ComfyUIError, ComfyUITimeout, ComfyUIClient
from .config import Settings, load_settings
from .openai_api import RequestError, image_response, parse_size, validate_n
from .templates import Templates, build_generation_graph, find_save_node_id, load_templates


@dataclass
class AppContext:
    settings: Settings
    templates: Templates
    comfyui: ComfyUIClient


def _as_int(value) -> int | None:
    if value is None:
        return None
    try:
        return int(value)
    except (TypeError, ValueError):
        raise RequestError("n must be an integer")


async def collect_outputs(ctx: AppContext, entry: dict) -> list[str]:
    save_id = find_save_node_id(entry["prompt"][0])
    saved = (entry.get("outputs", {}).get(save_id) or {}).get("images") or []
    if not saved:
        raise ComfyUIError("no saved images in output")
    data = await ctx.comfyui.fetch_image(
        saved[0]["filename"], saved[0].get("subfolder", ""), saved[0].get("type", "output")
    )
    return [base64.b64encode(data).decode()]


def create_app(settings: Settings | None = None, comfyui_client: ComfyUIClient | None = None) -> FastAPI:
    settings = settings or load_settings()
    workflow_dir = Path(settings.workflow_dir)
    if not workflow_dir.is_absolute():
        workflow_dir = Path(__file__).resolve().parent.parent / workflow_dir
    templates = load_templates(workflow_dir)

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        client = comfyui_client or ComfyUIClient(settings.comfyui_url)
        app.state.ctx = AppContext(settings, templates, client)
        try:
            yield
        finally:
            if comfyui_client is None:
                await client.aclose()

    app = FastAPI(title="oui-to-comfy-proxy", lifespan=lifespan)

    @app.exception_handler(RequestError)
    async def request_error_handler(request: Request, exc: RequestError):
        return JSONResponse(status_code=400, content={"detail": exc.detail})

    @app.exception_handler(ComfyUIError)
    async def comfyui_error_handler(request: Request, exc: ComfyUIError):
        return JSONResponse(status_code=502, content={"detail": str(exc)})

    @app.exception_handler(ComfyUITimeout)
    async def comfyui_timeout_handler(request: Request, exc: ComfyUITimeout):
        return JSONResponse(status_code=504, content={"detail": str(exc)})

    def get_ctx(request: Request) -> AppContext:
        return request.app.state.ctx

    def require_key(authorization: str | None = Header(default=None), ctx: AppContext = Depends(get_ctx)):
        key = ctx.settings.proxy_api_key
        if not key:
            return
        if not authorization or not hmac.compare_digest(authorization, f"Bearer {key}"):
            raise HTTPException(status_code=401, detail="invalid API key")

    @app.get("/health")
    async def health():
        return {"status": "ok"}

    @app.post("/v1/images/generations")
    async def generate(request: Request, ctx: AppContext = Depends(get_ctx), _=Depends(require_key)):
        body = await request.json()
        prompt = body.get("prompt")
        if not prompt or not str(prompt).strip():
            raise RequestError("prompt is required")
        n = validate_n(_as_int(body.get("n")))
        width, height = parse_size(body.get("size"))
        b64_list: list[str] = []
        for _ in range(n):
            graph = build_generation_graph(ctx.templates.generation, str(prompt), width, height, random.getrandbits(32))
            prompt_id = await ctx.comfyui.queue(graph)
            entry = await ctx.comfyui.wait(prompt_id, ctx.settings.timeout, ctx.settings.poll_interval)
            b64_list.extend(await collect_outputs(ctx, entry))
        return image_response(b64_list)

    return app


app = create_app()
```


Finally add this route inside `create_app`, directly after the `generate` route:

```python
    @app.post("/v1/images/edits")
    async def edit(request: Request, ctx: AppContext = Depends(get_ctx), _=Depends(require_key)):
        form = await request.form()
        prompt = form.get("prompt")
        if not prompt or not str(prompt).strip():
            raise RequestError("prompt is required")
        n = validate_n(_as_int(form.get("n")))
        files = [v for k, v in form.multi_items() if not isinstance(v, str) and IMAGE_PART_RE.match(k)]
        if not files:
            raise RequestError("at least one image is required")
        if len(files) > MAX_IMAGES:
            raise RequestError(f"at most {MAX_IMAGES} images are supported")
        batch = uuid.uuid4().hex[:8]

        async def upload(i: int, f) -> str:
            data = await f.read()
            ext = mimetypes.guess_extension(f.content_type or "") or ".png"
            return await ctx.comfyui.upload_image(data, f"oui-to-comfy-proxy_{batch}_{i}{ext}", f.content_type or "application/octet-stream")

        filenames = list(await asyncio.gather(*[upload(i, f) for i, f in enumerate(files, start=1)]))
        b64_list = []
        for _ in range(n):
            graph = build_edit_graph(ctx.templates.edit, str(prompt), "", filenames, random.getrandbits(32))
            prompt_id = await ctx.comfyui.queue(graph)
            entry = await ctx.comfyui.wait(prompt_id, ctx.settings.timeout, ctx.settings.poll_interval)
            b64_list.extend(await collect_outputs(ctx, entry))
        return image_response(b64_list)
```

The non-str values in `form.multi_items()` are `starlette.datastructures.UploadFile` file parts; their multipart order is preserved, which is why image order reaches `image_1..image_N` intact.

```markdown
# oui-to-comfy-proxy

OpenAI-compatible proxy that serves Qwen Image 2.1 (running in ComfyUI) to
Open WebUI. It translates `/v1/images/generations` and `/v1/images/edits`
into ComfyUI prompt graphs built from the templates in `workflows/`,
mapping any number of edit input images (1-16) onto the workflow's
`images.image_1..image_N` slots automatically.

## Run

    uv sync
    export COMFYUI_URL=http://127.0.0.1:8188
    uv run uvicorn oui-to-comfy-proxy.main:app --host 0.0.0.0 --port 8000

## Configuration (environment)

| Var | Default | Meaning |
|---|---|---|
| `COMFYUI_URL` | `http://127.0.0.1:8188` | ComfyUI base URL |
| `MODEL_NAME` | `qwen-image-2.1` | Model ID served at `/v1/models` |
| `WORKFLOW_DIR` | `./workflows` | Template directory (relative paths resolve from the repo root) |
| `TIMEOUT` | `600` | Max seconds to wait for a ComfyUI run |
| `POLL_INTERVAL` | `0.5` | Seconds between `/history` polls |
| `PROXY_API_KEY` | *(unset = open)* | Required Bearer key on `/v1/*` when set |
| `HOST` / `PORT` | `0.0.0.0` / `8000` | Bind address |

## Open WebUI setup

Image generation: engine `openai`, base URL `http://<proxy-host>:8000/v1`,
API key = your `PROXY_API_KEY` (any string if the proxy is open), model
`qwen-image-2.1`, size as desired.

Image editing: engine `openai`, same base URL and key, model
`qwen-image-2.1`. Leave `IMAGE_EDIT_SIZE` on auto - the edit output size
always follows the first attached image (rounded to a multiple of 32), so
attach images in the order you expect them to be referenced.

## Workflows

Templates live in `workflows/`. Nodes are matched by `class_type`, so you
can renumber or rename node IDs freely. The proxy overwrites the prompt,
seed, size (generation), and input images (editing) on every request;
everything else (model loaders, cache, switch, save settings) is used as-is.
To change the model or sampler, edit the template JSON.

## Tests

    uv run pytest
```
